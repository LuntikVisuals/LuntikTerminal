# LuntikTerminal

**Скрытый установщик с терминалом в стиле Windows CMD**

Через LuntikTerminal скачивается и устанавливается **LuntikStore**.
После установки ярлык LuntikTerminal исчезает с рабочего стола.
Найти его снова можно только внутри LuntikStore.

## Как это работает

1. Запускаешь LuntikTerminal
2. Видишь плавную загрузку на фоне бинарного кода `0` `1`
3. Постепенно появляются две руки, тянущиеся друг к другу
4. После загрузки открывается терминал в стиле Windows CMD (`C:\\>`)
5. Через команды скачиваешь и устанавливаешь LuntikStore
6. После успешной установки ярлык Terminal пропадает

## Команды терминала

| Команда | Описание |
|---------|----------|
| `help` | Список доступных команд |
| `list` / `apps` | Каталог доступных приложений |
| `info <название>` | Подробная информация о приложении |
| `auth` / `login` | Авторизация (обязательный шаг) |
| `download <название>` | Начать загрузку приложения |
| `verify <название>` | Проверка целостности файла |
| `install <название>` | Установка скачанного APK |
| `status` | Текущий статус загрузок и установок |
| `clear` / `cls` | Очистить экран терминала |
| `exit` / `quit` | Выход |

## Как скачать APK

1. Перейди во вкладку **Actions**
2. Открой последний успешный запуск **Build APK**
3. Скачай артефакт `luntikterminal-debug-apk`
4. Установи на телефон (разреши установку из неизвестных источников)
